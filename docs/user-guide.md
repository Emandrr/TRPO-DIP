# Руководство пользователя СА-ЭКГ

Система анализа и хранения кардиологических исследований (отведение II). Съём ЭКГ в систему не входит: загружается готовый CSV.

Базовый URL веб-интерфейса (локально): `http://localhost:4200`. API: `http://localhost:8080`.

---

## 1. Пациент

### 1.1 Регистрация и вход

1. Откройте `/register`, укажите email и пароль (≥ 8 символов, буквы и цифры).
2. Войдите через `/login`.
3. До загрузки ЭКГ администратор должен отметить **согласие** на обработку данных. Без согласия загрузка вернёт ошибку доступа.

### 1.2 Личный кабинет (`/patient`)

| Раздел | Назначение |
|---|---|
| Медкарта | Просмотр ФИО, даты рождения, пола (заполняет врач) |
| Диагнозы | Диагнозы, рекомендации и назначения врача |
| Обследования | Только **принятые** врачом записи; статус опрашивается каждые 3 с |
| Загрузка ЭКГ | Выбор устройства, drag&drop CSV |

### 1.3 Загрузка CSV

1. Выберите устройство из списка.
2. Перетащите файл `.csv` или укажите его вручную.
3. При успехе файл принимается в очередь (`202`), открывается карточка записи.
4. При ошибке валидации показывается код проверки и номер строки (если применимо). Файл **не** сохраняется.

Требования к CSV (кратко): UTF-8 без BOM; колонки `value`, `timestamp`, `errors`; частота 250 Гц; доля непригодных отсчётов ≤ 30 %.

### 1.4 Просмотр принятого обследования

После принятия отчёта врачом в списке обследований доступны:

- метаданные и статус;
- краткий отчёт (отведение II, ЧСС и др.);
- график сигнала (обзор + окно 10 с), переход к аномалиям по списку.

## 2. Врач

Учётную запись создаёт администратор. При первом входе по временному паролю обязательна **смена пароля**.

### 2.1 Рабочее место (`/doctor`)

1. **Пациенты** — список закреплённых администратором.
2. Карточка пациента:
   - **Медкарта** — создание/правка/удаление (с подтверждением);
   - **Диагнозы** — CRUD диагнозов, рекомендаций, назначений;
   - **Обследования** — все записи закреплённых пациентов со статусами.

### 2.2 Работа с отчётом ЭКГ

1. Откройте запись в статусе анализа/`Done`.
2. Просмотрите график и список аномалий.
3. При статусе отчёта `Pending`:
   - **Принять** или **Отклонить** (диалог подтверждения, необязательный комментарий).
4. Можно создать диагноз с привязкой к выбранным аномалиям (чекбоксы).

Даты в формах — `DD.MM.YYYY`. Пол в медкарте — «мужской» / «женский».

### 2.3 Ограничения доступа

- Доступ только к **закреплённым** пациентам.
- Чужой пациент → отказ (403).
- Пациент видит чужие данные как «не найдено» (404).

## 3. Общие замечания

- Интерфейс на русском языке.
- Адаптивная вёрстка ориентирована на ширину от 360 px.
- При потере сессии выполните вход заново.
- Необратимые действия (удаление медданных, accept/reject) требуют подтверждения в диалоге.
