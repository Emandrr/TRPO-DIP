# Программа и методика испытаний (ПМИ) СА-ЭКГ

Документ составлен по структуре ГОСТ 34.603-92 применительно к приёмочным испытаниям ПО.

## 1. Объект испытаний

Программный комплекс **СА-ЭКГ**: backend (.NET 10), frontend (Angular 21), PostgreSQL, DuckDB, Docker Compose.

## 2. Цель испытаний

Проверить соответствие реализации требованиям ТЗ (разделы 4–5 плана) и готовность к опытной эксплуатации.

## 3. Виды испытаний

| Вид | Содержание |
|---|---|
| Автоматические unit | CSV, фильтры, QRS/метрики, валидаторы медданных, purge, SQL-safety |
| Автоматические integration | auth, upload, admin (при наличии Docker) |
| Сквозные e2e (раздел 8 плана) | 12 сценариев (ручные / Playwright) |
| Эксплуатационные | healthcheck, backup/restore, restart API |

## 4. Условия

- ОС: Windows/Linux с Docker Desktop / Docker Engine.
- Браузер: Chromium/Chrome, viewport от 360×640.
- Тестовые CSV: генератор `EcgCsvGenerator` / файлы из `tests` при наличии.

## 6. Критерии приёмки

1. Unit-тесты backend зелёные в CI.
2. Frontend `npm run build` успешен.
3. Сценарии e2e §8 пройдены или зафиксированы отклонения в протоколе.
4. Доступность API по `/health` ≥ 95 % за период наблюдения (заполняется в протоколе).
5. Восстановление из бэкапа подтверждено.
