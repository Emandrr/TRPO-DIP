## Эталоны UX (D19 / P7.3)

Источники: `docs/references/ecg-24h-viewer.html`, `docs/references/ecg-report-example.png`, PDF в `docs/references/`.

### Просмотрщик 24 ч (`EcgChart`)

По образцу HTML-демо:

1. Верхний обзорный график ЧСС/тренда на всю длительность записи (для 24 ч — шкала 00:00…24:00).
2. Выделение интервала мышью/касанием; клик по часу → час целиком.
3. Нижний детальный график сигнала: окно **10 секунд** внутри выбранного интервала, ползунок позиции.
4. Подпись интервала и средняя ЧСС по выделенному фрагменту.
5. Подсветка аномальных интервалов на обзоре; клик по аномалии → переход к интервалу (P7.3).
6. Разрывы/`Error` отображаются на шкале (план 6.1 / D16).

### Отчёт (верстка, приложение Б)

По образцу скрина/PDF «ЭКГ за 24 часа: выявленные состояния»:

1. Заголовок отчёта на русском.
2. Для каждой аномалии/состояния — блок:
   - нумерованный заголовок состояния;
   - строка `Интервал: HH:MM:SS – HH:MM:SS` и `ЧСС ср. ≈ N уд/мин`;
   - узкий 24-часовой тренд с серой подсветкой интервала;
   - детальная полоса ЭКГ ~10 с с сеткой и подписью времени окна.
3. Структура **данных** отчёта — строго §6.7 плана; верстка следует эталону, не меняя контракт.
4. Дисклеймер для демо/синтетики допустим только в демо-материалах; в прод-отчёте — стандартные поля §6.7 + «Принято отведение II» (D6).

## Стиль исходников

В файлах кода и конфигурации (C#, TypeScript, HTML, CSS, YAML, Dockerfile, JSON кроме строковых значений) **комментарии не пишутся**: ни `//`, ни `/* */`, ни XML-doc (`///`), ни `#` в YAML/shell-скриптах проекта, ни HTML-комментарии. Пояснения, решения и TODO — только в `docs/*.md`.
